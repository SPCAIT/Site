# Одностраничный сайт с логотипом

В архиве:
- `index.html` — готовый одностраничный сайт;
- `logo.png` — логотип, вставленный в верхнее меню и favicon;
- `README.txt` — краткая инструкция.

Как посмотреть локально:
1. Распакуйте архив.
2. Дважды нажмите на `index.html`.
3. Сайт откроется в браузере.

Что можно заменить позже:
- `info@your-domain.kz` — на вашу реальную почту.
- `+7 (___) ___-__-__` — на телефон.
- Тексты направлений деятельности — при необходимости.
